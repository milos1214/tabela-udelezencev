# Tabela udelezencev

Projekt prikazuje znanje backend orodja z c#

# Navodila za zagon strežnika

## Za zagon strežnika sledite spodnjim korakom

Odprite terminal in se pomaknite v mapo API:

```bash
cd .\Api\
```

Zaženite strežnik z naslednjim ukazom:

```bash
dotnet run
```

Strežnik bo zagnan na portu 5289.

## Dostop do API-ja

Ko je strežnik zagnan, lahko dostopate do API-ja na naslednji povezavi

http://localhost:5289/api/osebe

Ta povezava vrne seznam oseb v JSON formatu.

**Za preverjanje delovanja je tudi uporabljen Postman.**
